# Product

## Register

product

## Users

Skill Hub is for developers, project maintainers, and internal administrators who manage Codex and Claude skills from a Windows desktop app. They browse marketplace skills, cache and install them locally, bind them to personal or project scopes, publish drafts, and maintain MinIO-backed market data.

## Product Purpose

Skill Hub should feel like a reliable skill operations workbench: fast to scan, precise about state, calm during repetitive work, and guarded around admin actions. The main value is not discovery spectacle; it is confidence when moving skills between the marketplace, local cache, target platforms, and project scopes.

## Brand Personality

Calm, technical, crisp, and capable. The interface should be modern and polished without feeling like a marketing landing page. It should prioritize readable structure, clear status, and low visual noise.

## Anti-References

- Marketing hero layouts, decorative gradients, floating glass cards, and ornamental effects.
- Deeply nested cards that make forms, lists, and details feel boxed-in several times.
- Oversized headings inside dense work surfaces.
- Color-only state communication, vague disabled states, and ambiguous install/update status.
- Modal-heavy flows for routine work.

## Design Principles

- Workbench first: the first viewport should expose the active workflow, not explain the product.
- Dense but humane: repeated items should be compact, aligned, and easy to compare.
- One component vocabulary: navigation, rows, chips, buttons, forms, and panels should share radius, borders, spacing, and state language.
- State before decoration: install status, sync health, active binding, draft validation, and publish readiness should be visually unambiguous.
- Guard admin actions: publishing, archiving, and remote project/category edits need clear hierarchy and stable action placement.

## Accessibility & Inclusion

Target WCAG AA contrast for text and controls. Interactive elements need visible focus states, non-color cues for important statuses, and reduced-motion behavior. Chinese and English labels should both fit without overlap in compact panels.
